## Consolidated EPG

Use this single EPG URL for all mapped UDPTV channels:

```text
https://raw.githubusercontent.com/djdoolky76/UDPTV/main/epgs/udptv-epg.xml.gz
```

The guide is rebuilt automatically every 12 hours. See
[`udptv/EPG_MAPPING.md`](udptv/EPG_MAPPING.md) for mapping recommendations and
the list of channels that do not currently have a trustworthy schedule source.
